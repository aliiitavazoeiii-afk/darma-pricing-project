# Darma Pricing Project | مرجع قیمت‌گذاری دارما

**وضعیت:** مستندسازی گفت‌وگوی قیمت‌گذاری شهریور و مهر ۱۴۰۵؛ این ریپو در حال حاضر کد اجرایی داشبورد ندارد.  
**آخرین به‌روزرسانی این مجموعه:** ۱۴۰۵/۰۷/۰۳ (۲۰۲۶-۰۹-۲۵).  
**نکته محرمانگی:** این مخزن عمومی است و فایل‌های آن برای عموم قابل‌مشاهده‌اند. اطلاعات شخصی حساب‌ها، نام گیرندگان پرداخت و تصاویر خام واریزی در این مخزن منتشر نشده‌اند.

## هدف کسب‌وکار
دارما تولیدکننده پوشاک با فروش اصلی در دیجی‌کالاست. هدف: افزایش تدریجی حاشیه سود پس از افزایش هزینه تولید، **بدون از دست‌دادن حجم فروش و جایگاه پک ۵**. مالک کسب‌وکار می‌گوید پک ۵ یکی از پرفروش‌ترین کالاهای دسته مد و پوشاک دیجی‌کالاست؛ این ادعا از داده داخلی فروش دارما یا منبع مستقل رتبه‌بندی در این پروژه تأیید نشده است.

## از کجا شروع کنم؟ — راهنمای چت‌های بعدی
1. **ابتدا کل [docs/PROJECT-HISTORY.md](docs/PROJECT-HISTORY.md) را بخوان:** هدف، پیش‌فرض‌ها، روایت تصمیم‌ها، بحث اعتباری/نقدی و تفکیک عدد تأییدشده از محاسبه فرضی.
2. **[docs/VERIFIED-BASELINE-1405-06.md](docs/VERIFIED-BASELINE-1405-06.md):** اعداد کنترل‌شده از فایل فروش شهریور و محدودیت‌های منبع.
3. **[docs/PRICE-PLAN-1405-07.md](docs/PRICE-PLAN-1405-07.md):** جدول قیمت منتخب پک‌های ۳/۴/۵/۶، پیشنهادهای قبلی که جایگزین شده‌اند و نحوه آزمون.
4. **[docs/DASHBOARD-SPEC.md](docs/DASHBOARD-SPEC.md):** دستور اجرایی ساخت باکس مستقل «پایش قیمت‌گذاری و عملکرد محصولات» در پروژه اصلی داشبورد و خروجی اکسل.
5. **[docs/OPEN-QUESTIONS.md](docs/OPEN-QUESTIONS.md):** فرض‌های هنوز تأییدنشده، ابهام هزینه اعتبار و آزمایش‌های لازم.
6. **[data/1405-06-pack-size-summary.csv](data/1405-06-pack-size-summary.csv):** داده تجمیعی بدون نام و مشخصات شخصی، بر اساس فایل شهریور.

## دستور ادامه کار برای یک چت تازه
«ابتدا README و پنج سند پیوندشده را کامل بخوان؛ بین آمار تأییدشده اکسل شهریور، گفته‌های صاحب کسب‌وکار، و سناریوهای فرضی تفکیک قائل شو. برای تغییر داشبورد، ریپوی اصلی `aliiitavazoeiii-afk/darma-general` و HEAD فعلی آن را جداگانه واکشی کن؛ هیچ تغییر کد یا نسخه را از این ریپوی مستندسازی حدس نزن. هیچ قیمت یا کارمزد اعتباری را خودکار اعمال نکن.»

## فایل‌های منبع گفت‌وگو، که در ریپوی عمومی منتشر نشده‌اند
- `darma-report-1405-06-01-1405-06-31.xlsx` — گزارش اصلی ماه؛ دارای شیت‌های حساب و پرداخت اشخاص.
- `darma-pricing-scenarios-1405-06.xlsx` — سناریوهای اولیه تولیدشده در گفت‌وگو؛ تحلیل آن مقدماتی است.
- سه اسکرین‌شات گزارش/واریزی شهریور؛ تصویر واریزی‌ها ممکن است اطلاعات بانکی و اشخاص داشته باشد.

برای بررسی موشکافانه سفارش‌ها یا تغییر الگوریتم تسویه، فایل‌های منبع را به‌صورت خصوصی به چت تحلیلگر بدهید. CSV تجمیعی این مخزن جانشین اطلاعات سفارش یا تسویه نیست.
