# Darma Pricing Project | مرجع قیمت‌گذاری دارما

**وضعیت:** مخزن مستندسازی تصمیم‌های قیمت‌گذاری، تولید، موجودی و طراحی سیستم پایش دارما؛ این مخزن در حال حاضر کد اجرایی داشبورد ندارد.  
**آخرین به‌روزرسانی:** ۱۴۰۵/۰۷/۳۰ (۲۰۲۶-۱۰-۲۲). آخرین قیمت‌های گزارش‌شده و مبنای هزینه در [docs/CURRENT-STATE-1405-07.md](docs/CURRENT-STATE-1405-07.md) آمده است؛ پیش از هر تصمیم تازه، صحت فعال‌بودن قیمت‌ها را در سیستم عملیاتی تأیید کن.  
**حریم خصوصی:** مخزن عمومی است. فایل‌های خام بانکی، حساب اشخاص و تصاویر دارای اطلاعات حساس در آن منتشر نشده‌اند.

## شروع سریع برای چت/عامل جدید
1. اول [docs/CURRENT-STATE-1405-07.md](docs/CURRENT-STATE-1405-07.md) را بخوان: قیمت‌های جدید اعلام‌شده، مدل هزینه، snapshot موجودی و وضعیت بازار.
2. سپس [docs/PROJECT-HISTORY.md](docs/PROJECT-HISTORY.md) را بخوان: تاریخچه تصمیم‌ها، دغدغه‌ها و منطق قیمت‌گذاری.
3. [docs/VERIFIED-BASELINE-1405-06.md](docs/VERIFIED-BASELINE-1405-06.md): اعداد تجمیعی کنترل‌شده از گزارش شهریور و محدودیت‌های داده.
4. [docs/PRICE-PLAN-1405-07.md](docs/PRICE-PLAN-1405-07.md): جدول اول مهر و پیشنهادهای تاریخی قبلی؛ برای قیمت جدیدتر از Current State استفاده کن.
5. [docs/DASHBOARD-SPEC.md](docs/DASHBOARD-SPEC.md): مشخصات باکس مستقل پایش قیمت‌گذاری، قواعد محاسبه و خروجی اکسل.
6. [docs/OPEN-QUESTIONS.md](docs/OPEN-QUESTIONS.md): فرض‌های تأییدنشده و داده‌هایی که پیش از تصمیم قطعی نیاز است.
7. [data/1405-06-pack-size-summary.csv](data/1405-06-pack-size-summary.csv): داده فروش شهریور به‌صورت تجمیعی و بدون مشخصات شخصی.

## آخرین قیمت‌های اعلام‌شده
این جدول در [docs/CURRENT-STATE-1405-07.md](docs/CURRENT-STATE-1405-07.md) آمده است و وضعیت فعلی گزارش‌شده را جایگزین جدول قدیمی اول مهر می‌کند. همه مبالغ تومان، سایزها به ترتیب M/L/XL/2XL/3XL:
| پک | قیمت‌ها |
|---|---|
| ۳تایی | 441,000 / 465,000 / 510,000 / 533,000 / 550,000 |
| ۴تایی | 575,000 / 610,000 / 649,000 / 678,000 / 711,000 |
| ۵تایی | 670,000 / 730,000 / 779,000 / 811,000 / 830,000 |
| ۶تایی | 830,000 / 896,000 / 933,000 / 973,000 / 1,017,000 |

هزینه مرجع اخیر برای قیمت‌گذاری 75,000 تومان/شورت اعلام شده است؛ اما با فرض پارچه 2.05 میلیون و کش 2.5 میلیون تومان، محاسبه سناریویی بر مبنای راندمان 765 شورت در 20 کیلو پارچه حدود 79,100 تومان/شورت می‌شود. فروشنده هنوز قیمت 2.05 میلیون را به‌عنوان قیمت جایگزینی اعلام کرده و معامله نقدی قطعی در آن سطح تأیید نشده؛ این دو عدد را یکی فرض نکن.

## پروژه داشبورد اجرایی
مالک پیش‌تر مخزن اصلی داشبورد را با نام `aliiitavazoeiii-afk/darma-general` ذکر کرده است. هنگام هر کار اجرایی، وجود مخزن، branch و HEAD فعلی را مستقیماً در GitHub بررسی کن. این مخزن `darma-pricing-project` فقط مرجع دانشی و مستندات است و تغییرات آن به‌خودی‌خود داشبورد تولید را تغییر نمی‌دهد.

## منابع خام خارج از مخزن عمومی
- `darma-report-1405-06-01-1405-06-31.xlsx` — گزارش اصلی شهریور، شامل شیت‌های مربوط به حساب/پرداخت.
- `darma-pricing-scenarios-1405-06.xlsx` — سناریوهای اولیه قیمت‌گذاری.
- `darma-pricing-monitor-v89.xlsx` — snapshot قدیمی‌تر پایش قیمت‌گذاری، تا حدود ۱۳ مهر.
- تصاویر موجودی/فروش تا حدود ۱۳ مهر.
  
این فایل‌ها در گفتگو بارگذاری شده بودند، اما برای حفظ حریم خصوصی و جلوگیری از اشتباه در لینک فایل، در این مخزن عمومی کپی نشده‌اند. برای محاسبات جدید از گزارش تازه و وضعیت عملیاتی جاری استفاده کن؛ اعداد snapshot را به‌عنوان موجودی امروز یا عملکرد قیمت‌های جدیدتر جلوه نده.
